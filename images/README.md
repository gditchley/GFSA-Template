# images

Figures used by the template and by individual problem files.

Place image files here (PDF, PNG, or JPEG). Reference them from `main.tex` or from a problem file with a path relative to the project root:

```latex
\includegraphics[width=0.8\textwidth]{images/free-body-diagram.pdf}
```

## Guidelines

- Prefer PDF for line art and diagrams; use PNG for screenshots or photos.
- Use short, descriptive file names with hyphens (`beam-loading.png`), not spaces.
- Do not put compiled LaTeX output or editor scratch files in this folder.

This file also keeps the folder in Git while it would otherwise be empty.
